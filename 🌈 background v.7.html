🌈 Rainbow Tab

Transform your browser tab with smooth animated rainbow colours.

📦 How to Use

Option 1: Download & Load
1. Click "DOWNLOAD EXTENSION"
2. Extract the ZIP file
3. Go to chrome://extensions
4. Enable "Developer mode" (top right)
5. Click "Load unpacked" and select the folder

Option 2: Manual Setup
Create a folder with the manifest.json below and follow steps 3-5 above.

📄 manifest.json

{
  "manifest_version": 3,
  "name": "Rainbow Tab",
  "version": "1.0",
  "description": "Beautiful rainbow colored new tab page",
  "action": {
    "default_title": "Rainbow Tab"
  },
  "chrome_url_overrides": {
    "newtab": "index.html"
  }
}

To customize the colors, edit the @keyframes bg section in the CSS:

Change the color values to your preferences and adjust animation timing as needed. The background will automatically cycle through all specified colors smoothly.

❓ Troubleshooting

Extension not showing?
Make sure you enabled Developer mode before loading unpacked.

Download button not working?
Try the manual setup option or check your browser permissions.

Need help?
Check the Chrome Web Store documentation for more info on loading extensions.
